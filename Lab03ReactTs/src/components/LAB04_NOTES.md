# Laboratory Activity 4 Notes

## useState

useState is used in the CounterPanel component to store and update the counter value. The Increment, Decrement, and Reset buttons trigger state updates.

## useReducer

useReducer is used in the FilterList component to manage items and their filter state. Actions such as add, toggle, and setFilter are dispatched to update the state.

## useEffect

useEffect is used in the ClockLabel component to update the current time every second using setInterval. The interval is cleared during cleanup to prevent unnecessary timers.

## Conclusion

This laboratory activity demonstrates how useState, useReducer, and useEffect can be used to handle state, events, and external effects in a React TypeScript application.
